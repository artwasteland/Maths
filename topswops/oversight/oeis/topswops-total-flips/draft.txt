%S 0,1,6,38,265,2115,18508,180260,1911505,22169434,277931375,3758940272,54349566758
%N Total number of steps in Conway's Topswops, summed over all n! starting decks of n cards.
%C Topswops (J. H. Conway): deal a deck that is a permutation of 1..n. Read the top card k; if k = 1, stop; otherwise reverse the order of the top k cards. Repeat. The process always terminates (Conway). a(n) is the sum, over all n! possible starting decks, of the number of reversals performed before the top card becomes 1.
%C Equivalently, a(n) = n! times the average number of Topswops steps for a random deck of n cards. The averages a(n)/n! are 0, 1/2, 1, 19/12, 53/24, 47/16, ... (n = 1, 2, 3, ...), growing roughly linearly in n (observed; no asymptotic claimed here).
%C Companion statistics of the same process: the maximum number of steps is A000375; the number of decks attaining that maximum is A123398; the number of decks that are NOT reachable as the result of any single reversal step (the "Garden of Eden" decks) is A000255(n-1) — those are exactly the permutations with no fixed point in positions 2..n.
%C Every step-count between 0 and A000375(n) is attained by some deck, so the number of distinct step-counts is A000375(n) + 1 (checked for n <= 10).
%D D. E. Knuth, The Art of Computer Programming, Vol. 4A: Combinatorial Algorithms, Part 1, Addison-Wesley, 2011, Section 7.2.1.2 (Topswops as exercise/discussion).
%H Wikipedia, <a href="https://en.wikipedia.org/wiki/Topswops">Topswops</a>.
%H N. J. A. Sloane et al., OEIS, <a href="https://oeis.org/A000375">A000375</a> (Topswops: maximum number of steps).
%e n=3: the 6 decks 123,132,213,231,312,321 take 0,0,2,1,2,1 steps respectively; a(3) = 0+0+2+1+2+1 = 6.
%e n=4: summing the step counts of all 24 decks gives a(4) = 38.
%Y Cf. A000375 (maximum steps), A123398 (number of maximizing decks), A000255 (Garden-of-Eden decks, offset by 1), A000142 (n!).
