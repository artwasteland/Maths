## 3. The code

## 6. Surprises

GP-10's matcher caps hosts, not only patterns, at 10 vertices. GP-10 is absent from this worktree's base, and levels
13+ from the repository. The 398 bite hard with depth: at (18,46), 61 of AMP's 84 F-free graphs contain a member (23
left; AMP 16 embeddable), 12,767 of that cell's 19,708 parents contain one, 703 of the 743 real level-21 parents
contain one, and all four (22,61) candidates contain one. `--mutation-drop-first-badset` aborts on real cells
("automorphism left the neighbourhood domain") and only works on trivial-automorphism parents like K3. udfilter's
Mode 74 loader is lenient (a duplicate edge inflates m and makes K4 unmatchable, so "C~" passes; unbalanced brackets
accepted; no order guard), and the new build reproduces this exactly, as required; the Mode 398 pin closes it for the
new list. Every slice's `counts.json` holds whole-level counts at levels 12-13, so summing across slices overcounts
48x. networkx VF2 takes about a minute per 12-vertex negative. The u(23) contract appeared mid-work and matches the
design. A few checks lasting seconds to about two minutes overlapped the two long runs.
