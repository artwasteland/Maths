# O1 PTS enumerator report

## WHAT WORKS

The program is ptsenum.c, built as ptsenum with libnauty. The incidence graph has
one colour class for points and one for blocks. densenauty produces the canonical
graph. For each parent, nauty automorphism generators are collected and only one
admissible block from each parent orbit is tried. The child is then accepted only
when deletion of its canonically last block, followed by canonical labelling, returns
the current parent. This is the canonical-parent form of the automorphism-orbit
canonical augmentation test.

The leave parity is derived in feasible() from 2*r3 + r2 = v - 1. The pair count
derives the leave edge budget as v*(v-1)/2 - 3*b. The per-point residual bounds and
the remaining block and leave budgets are used before child canonicalisation.

Build check:

    make clean && make
    rm -f ptsenum
    cc -std=c17 -O3 -Wall -Wextra -Wpedantic -I/usr/include/x86_64-linux-gnu/nauty ptsenum.c -lnauty -o ptsenum

Measured controls:

    ./ptsenum --sts 7 --output final-sts7.txt
    count=1 wall_seconds=0.003440 canonical_calls=37

    ./ptsenum --sts 9 --output final-sts9.txt
    count=1 wall_seconds=0.030525 canonical_calls=1233

The generated line counts for these controls were:

    wc -l final-sts7.txt final-sts9.txt
      1 final-sts7.txt
      1 final-sts9.txt

The generated lines use integer separators, so point labels 10 and above are
unambiguous. A manifest is written as manifest-v-b.json, including the count,
leave edge count, parity mode, and run counters.

Orbit mutation, through the real executable:

    ./ptsenum --sts 7 --break-orbit --output final-broken7.txt
    count=3 wall_seconds=0.005459 canonical_calls=28

    wc -l final-broken7.txt
      3 final-broken7.txt

The control was made to fail by bypassing the orbit and canonical-parent acceptance
test. The correct count is 1 and the broken path emitted 3 copies of the same
canonical STS(7) line.

Parity mutation, through the real executable:

    ./ptsenum --pts 6 3 --leave-even --output final-parity-good.txt
    count=0 wall_seconds=0.000978 canonical_calls=1

    ./ptsenum --pts 6 3 --leave-even --drop-parity --output final-parity-bad.txt
    count=1 wall_seconds=0.002094 canonical_calls=9

    wc -l final-parity-good.txt final-parity-bad.txt
      0 final-parity-good.txt
      1 final-parity-bad.txt

    python3 - <<'PY'
    import re
    s=open('final-parity-bad.txt').read().split(':',1)[1]
    a=list(map(int,re.findall(r'\d+',s))); d=[0]*6
    for i in range(0,len(a),3):
        for x in a[i:i+3]: d[x]+=1
    print('leave_degrees=', [5-2*x for x in d])
    PY
    leave_degrees= [3, 3, 3, 1, 1, 1]

The intentional mutation ignored the requested even parity. The emitted system has
odd leave degrees, so this test goes red through enumeration rather than calling the
parity predicate directly.

## WHAT DOES NOT

The required STS(13)=2, STS(15)=80, PTS(13,23), PTS(13,24), PTS(14,27), PTS(14,28),
and PTS(15,32) final controls were not completed in this run. No target count is
claimed.

The attempted target command was:

    timeout 300 /usr/bin/time -f 'TIME %e' nice -n 10 ./ptsenum --pts 13 23 --leave-even --output pts-13-23.txt

Before interruption it reached:

    level 8 -> 9768 systems, canonical calls=161217
    level 9 -> 71311 systems, canonical calls=1396979
    level 10 -> 482568 systems, canonical calls=10905029

There was no final output count. The required STS(15) deletion comparison therefore
also has no measured result.

The manifest does not yet include a SHA-256 field for the generator binary. The
measured binary hash was:

    sha256sum ptsenum
    202307ce66821f6fdd019396177bce02cb41434697bfb0fbf5030018d176ad8c  ptsenum

The hash must be inserted or generated by the supervisor's packaging step before a
certificate claim.

## UNCERTAIN

* The STS(13), STS(15), and all four requested PTS target counts remain unexercised
  to completion.
* --delete-point was implemented for a 15-point STS input file, but no completed
  STS(15) file was available, so its independent count and agreement were not tested.
* --leave-graph graph6 parsing and a complete leave-type histogram were not
  exercised.
* The output and manifest were not checked against an independent parser.
* No memory-sanitizer run was completed on a large instance.
* The exact canonical augmentation count is validated only by the STS(7) mutation
  and the two small positive controls. Large-level duplicate absence remains work
  for the supervisor.

## PROPOSED CONTRACT AMENDMENTS

1. Define the parity mutation as using a deliberately wrong requested selector,
   then dropping that selector. A literal removal of the parity constraint cannot
   create a mathematically odd leave degree for a triple system, because
   r2 = v - 1 - 2*r3 forces the parity identically. The (6,3) mutation above
   tests the executable filter while respecting this identity.
2. Permit the builder to report a bounded timed prefix for the large controls,
   separately from a completed count. The present contract requires all large
   controls before handoff but gives no staging format for a run that is correctly
   bounded to ten minutes per test.
