EMBED
embed/gp10embed.py: order cap is 64, not 10; lattice/constructive/host/numeric proposals are generic. Limits, per-graph seed, timeouts and exact checks can remain. Warm imports and host database outside per-graph timing. Use explicit scratch output paths.
embed/exact.py: graph parser cap 4096; local certificate degree cap 256 and 192 interval refinements; these are producer limits, not n=10 assumptions. Frozen official exact checker has no 256-degree limit and permits 2048 refinements. Never increase budgets silently.
embed/numeric.py: n-generic; three starts, weak separation penalty, max_nfev=160. It stops on edge residual alone even when points coincide. reconstruct greedily picks one circle branch and rationalizes free angles with denominator at most 12. Numeric success is not a certificate. General exactification needs real engineering; simply changing an order cap does not repair branch loss or flexible components.
embed/algebraic.py: constructor generic, but points_from_cert accepts only Q or the particular quartic Q(sqrt(3),sqrt(11)); certificate defaults to degree cap 32; constructive removes degree<=2 vertices and attempts to rebuild only a limited finite set of placements (128 tries). This is not a general GP10-certificate extension engine.
embed/rigid_system.py: generic_rank explicitly rejects n>10 (46). Raising to 11 is small; all-subset Laman bound goes from 1024 to 2048 subsets, manageable at 11. Pins only propose embeddings; pinned infeasibility must never refute the unpinned graph. generic_exact, round2 and curve_exact depend on this function and inherit its ceiling.
embed/{generic_exact,msolve_exact,round2,round2_phase,official_check,gp_field}.py: scratch/output whitelists and fixed /tmp/gp10-* paths; relocate/configure. generic_exact only allows module directory or /tmp/gp10-embed. msolve wrapper pins binary hash and buffer patches, uses one solver thread, caps output/field degrees and exactification time. Deployment needs version-checked setup, not unverified binary patching. gp_field's radical field extension supports generic n, caps degree 256 and PARI memory; can be reused for an ordinary E-exact certificate after adjoining the circle square root.
embed/{hosts,lattice}.py: search generic; finite catalog is a source of witnesses, not a complete search. GP host expressions/data can carry forward and every extracted embedding still gets checked. Existing host certificates live in embed/host_certificates.json; exact B10 decisions are NOT in data/: cloud/lean3/records.jsonl.gz is the final accepted stream. It contains 3879 direct E-exact and 28774 E-ptr records (measured extraction), 32653 embeddings total. Resolve pointers and compose label maps; G-v need not be biconnected and then has no direct B10 key. Build exact block gluing for those cases or report missing coverage. One G-v embedding may be unextendible although another embeds G. Try all eligible vertices, both circle intersections, and alternative base embeddings/free angles. Failures are UNKNOWN.
Historical embed rounds/reports/measure.py/prepare_* use B10 paths, fixed cohorts/counts, old scratch locations and hand-selected graphs. Keep archival; new parameterized B11 CLI/manifest instead of bulk search-and-replace.

REFUTE
refute/{gp10refute,algebra,amp_core,dag,quadratic_sos,circle_helpers}.py: core search/identities use graph.n; no n<=10 barrier. tree_search, null/real and DAG searches can be measured at 11 now. Saturation, frame and branch choices, rather than order parsing, govern success. Default tree state budget 200; CAS timeouts and hard process/memory isolation matter. DAG output must fit 256 rows and 8 MiB.
refute/graphs.py: validate_forbidden demands a prefix of forbidden-74.json; forbidden_canonical caches only 74. Make the list/profile explicit and bind prefix/index semantics to the run. tu_search itself accepts a supplied pattern collection and known endpoints; its Python matching repeatedly scans the lists. Reuse a fast proposer but keep independent map/chain replay.
SCRATCH constants are imported by value in graphs, algebra and gp10refute. Redirect every copy plus TMPDIR/SQLITE_TMPDIR, as drive/integration.py already demonstrates. Merely exporting TMPDIR is insufficient. Targeted algebra can launch Singular; count child processes in the desktop ceiling.
GP74-special analytic39/null39/quotient39/centroid66, focused-control and candidate/round scripts use global indices or frozen B10 membership. Reuse sound geometric identities/templates via an explicit map; do not treat these one-off CLIs as general B11 tools. Legacy exporter may translate old Sturm representations but needs independent recheck.
cloud/targeted.py is already n-generic and uses old sample-profile checker; fixed F9 limit can remain for direct polynomial certificates. Needs parameterized paths/environment, robust JSON receipt/status, memory and whole-call timeout, resumable artifacts, dependency closure when using TU/new known refutations. Current helper writes a certificate before checker result and prints a line; ingestion must consume structured checker status and exact record identity.
cloud/multistart.py is n-generic, numeric triage only. It has no exactification, checkpoint/resume, wall/memory supervision or thread caps, runs 600 starts by default and max_nfev=2000. Wrap or replace. Never count numeric drawings as decided; ship coordinates plus edge/separation diagnostics into exactification jobs.

DRIVE / ASSEMBLY
Graph6, Poset, aggregation and monotonicity maps are generic for n=11. graph6.py's extended-header code is irrelevant at 11 (one-byte order). Do not refactor it in this project. Fixed-size caches of 250000 canonical forms and 150000 other graph facts can consume substantial memory.
production driver.py: prefix validation against F74 (551-555); profile argparse accepts sample/B10 (783); actual producers require --processes 1 because they have workers (269); state/seeds/certificates held in RAM and rewritten repeatedly. Original full driver reached 13.96 GB and was killed in GP10, so using it unmodified for B11 is not viable even on 15 GB workers.
drive/seeds.py: F-prefix length->order map ends 74:9 (38), checker path, validation sample manifests; external records are admitted only as exact hosts, not external refutation dependencies. New F398 endpoints need indexed trusted-list support or records inside a dependency-closed run. Detect contradictory duplicate seeds; do not let first-seed-wins hide a rejected early proof and valid later proof.
drive/runfiles.py: B10 frozen digest, limit9, B10/sample profiles, default derive when B10; add independent B11 profile and explicit complete controls. run_b10, assemble_b10, controls, run_controls, reproduce_integration and audit_round* hardcode B10/cohorts/predictions. New B11 wrappers, retaining old controls as regression fixtures.
lean_assemble.py is graph-order-generic and certificate-offset-based, but still json.loads the ENTIRE POSET, stores Python relation dicts twice, and stores input sets/verdict/pointer dicts. 'Lean' is not constant memory. Replace relation storage with integer IDs and compact CSR/mmap or indexed SQLite; certificate bytes stay on disk. Preserve first-source provenance while selecting accepted certificates; explicit counters for oversize, invalid, missing, duplicate, conflict. Never put all proof objects in RAM.
Full B11 compact relation pilot uses 8-byte parent/child IDs, not JSON. To emit pointer certificates, store permutation witnesses or regenerate/verify a map only when choosing a pointer. The poset is a heuristic acceleration; final checker must derive minimality from actual graph edge deletions and validate each pointer independently.

DATA / FREEZE / RESULT
Existing data contains B4p...B9p and B10 only. New B11.g6 must be canonical labelg default, byte sorted unique, hash-frozen and accompanied by replay/recount evidence. Existing 398 filter source already supports n11. The graph edge cap m<=24 follows 9m<=11*u(10)=220 from all ten-vertex deletions; bind u(10)<=20 to the checked lower classification. geng -k excludes K4 by the already-proved smaller obstruction; account explicitly for this restricted enumeration domain.
recount/matcher.c: MAXN=10, MAXPAT=128; raise to 11/at least398 (16-bit masks still suffice) and make pattern order10 accepted. check_inputs.py, run_recount.sh, verify_witness inputs and reporting hardcode F74/B10. G0 needs independent byte-identical canonical survivor list, valid witnesses AND coverage of the generated stream by survivors+rejections. Our consultation enumeration is not G0: it uses existing udfilter implementation and does not retain every rejection witness.
The u22 filter's udf_witness.pair_a/pair_b are gadget-label indices. Map them through witness.map. Its CLI prints these raw indices in pair; do not use that pair directly as a host edge. This was detected while prototyping closure; measurements use the corrected mapped pair and independent certificate checks.
write_result.py/result_summary.py/build_bundle.sh/independent_audit.py and connected/gallery tools have B10 paths, L10 names, +74 counts and eight-control gates. The new writer must read the B11 report/list, insist on all gates and reviewed-profile hash, reject conditional ACCEPT, and contain no producer-estimated counts. Existing writer checks G5-response file existence rather than binding review to the new checker: tighten provenance for B11. Preserve all old result hashes.

Further kernel limits: delegated verify_refutation limits trees to 100000 nodes and depth1000; these are certificate complexity limits, not host order10. It does not call the old u22 CLI's default (22,61) run gate. The legacy refute/export_checker.py explicitly refuses TU certificates: do not use it as the new dependency packer.
Integration note from scratch measurements: embed and refute both have a module named round2.py. Importing all source directories into one undifferentiated sys.path can select the wrong module. Prefer isolated entry points or explicit namespaced loading; test mixed-stage deployment. Degree-two PARI extension must remap arbitrary stored field generators, including non-monic input polynomials, before applying nfroots/rnfequation. Merely copying coordinate coefficients into a newly reduced number field is wrong; final E-exact checks catch it.

TU quotient opportunity: for a graph with no forbidden endpoint, adding all six-gadget forced edges preserves embeddability in both directions. Closed F398-free graphs are among the 294516 no-TU-hit B11 members. Thus one may search closed representatives and lift positive results by E-super and negative ones by a nonempty R-tu chain to a checked closed representative. Ordinary subgraph propagation cannot carry a refutation from a supergraph back to its subgraph. TU reversal plus ordinary R-sub pointers can create cycles; require direct seed proof and acyclic dependencies, not mutual assertions around a quotient class.
