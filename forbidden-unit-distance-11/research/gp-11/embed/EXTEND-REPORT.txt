WHAT IS CERTIFIED

For each eligible v, keep contains the other vertices in increasing input order.
The deletion is canonicalized; its old_to_new map selects coordinates from
EmbeddingIndex.resolve, which has already composed any GP-10 E-ptr chain.
Coordinates therefore return to the labels of the actual G-v.

The PARI wrapper selects an irreducible factor at the stored real interval,
then uses polredbest's returned generator map on EVERY coordinate.
It never copies old coefficients into a new number field unchanged.
For D = B-A and q = D.D, the candidates are
  (A+B)/2 +/- (D_y,-D_x) * sqrt(1/q - 1/4).
nfroots first looks for the square root in the base field.
rnfequation adjoins it only when needed, again mapping every stored coordinate.
Exact equality in this field tests each proposed point against every old point.
An occupied first intersection leads to the other branch, then other vertices.

The output field is generated by an explicitly constructed linear combination
of coordinates; an exact matrix identity proves their expressions in it.
The emitted polynomial is its primitive integer minimal polynomial.
The emitted rational interval has a strict exact sign change and a Sturm count
of one; it also handles rational generators that land exactly on dyadic points.
Approximate root selection and PARI output are untrusted proposals.
Only the frozen checker can accept the final edge equations and injectivity.
The wrapper requires GP_FIELD_OK, not merely a successful process exit status.
There is no new certificate type, checker rule, or trusted extension lemma.

SEARCH POLICY AND LIMITS

One stored placement per base; vertices in increasing canonical label order.
Graph budget: 3 wall seconds, including the online frozen exact check.
PARI attempt budget: 1 second while another eligible vertex remains.
The last eligible vertex can use the remaining graph budget.
Field degree cap: 256.
The RNG seed is derived only from SHA256(canonical graph6).
Shards, input positions, and worker identity do not affect that seed.
As with the prototype, fixed wall-budget UNKNOWN outcomes can vary with load.
The checked success is deterministic for the same completed attempt sequence.

Block gluing is deliberately left unimplemented under the job's permitted
UNKNOWN option; skipped non-biconnected bases have an explicit reason.
Failures of a particular stored placement are not proofs of nonembeddability.
The output contains no refutations.

CONTROLS

The red controls start from an actual square produced by the extender.
They pass through the frozen JSON and exact-rational parsers.
Their asserted rejection reasons have these full messages:
  coordinate coefficient increased by 1/7: edge_equation: (0, 1)
  new vertex forced onto an existing non-neighbour: exact_collision: (1, 2)
  coordinates assigned through a wrong permutation: edge_equation: (0, 2)
The coordinate and permutation mutations pass the frozen exact checker with
the edge set removed, so no collision or syntax defect can mask a lost edge rule.
The collision mutation preserves all edge equations; the checker tests those
before reaching exact_collision.
After EACH red control, the real unmutated certificate is checked again and
required to produce its original acceptance result.

SURPRISES AND LIMITS

The first implementation let the first PARI conversion spend the entire graph
budget: its pilot yielded 440/500, with 14 graph timeouts.
Thirteen of those had only reached their first eligible vertex.
Adding an attempt limit yielded 448/500 with five graph timeouts.
Nine former UNKNOWNs became embedded and one earlier embedding became UNKNOWN;
budget scheduling and system load can change which expensive placements finish.

Some stored intervals are narrower than a fresh 160-bit isolator.
The isolator therefore refines until it lies strictly inside the stored interval.
Rational primitive elements also need a bracket that straddles an exact dyadic
root instead of putting that root at an endpoint.
Both issues now have working controls; ordinary frozen verification still
decides every accepted record.

Further coverage needs block gluing, alternate base embeddings, or another
producer; increasing a timeout alone is not an existence argument.

The two independent samples share 4 graphs. All 3 shared embeddings
with the same completed attempt route are byte-identical across their
different sample positions. The larger sample includes accepted fields
of degrees 6, 10, and 18 as well as powers of two.
