# research/penney-mary — Penney's game on an *m*-sided die

The Penney dominance tournament generalised from a coin to a fair **m-symbol
alphabet**. Vertices = the *mⁿ* length-*n* words; edge A → B iff *A* appears
before *B* (in an i.i.d. uniform m-ary stream) with probability > ½. This is the
m > 2 sibling of `research/penney-tournament`.

## Files
- `engine.mjs` — exact rationals (`Q`); word enumeration; **three** probability
  engines: generalised Conway leading-numbers (`pAfirst_conway`), first-principles
  absorbing-Markov (`pAfirst_markov`), and Monte-Carlo (`pAfirst_mc`); the
  tournament + its invariants; `girth`.
- `verify.mjs` — **18/18.** Calibrates Conway vs Markov on every pair (full for
  small (m,k), sampled larger); the **honesty anchor** (reproduces the published
  binary sequences exactly); Monte-Carlo sign check; structure (antisymmetry, the
  m! relabelling automorphisms); the girth/onset table; prints + writes
  `results.json`.
- `explore.mjs` — the concrete objects the stratum shows (the 3-die length-2
  triangle `01 ▸ 12 ▸ 20`, each 3/5; the binary contrast).
- `results.json` — machine-readable dump (regenerated by `verify.mjs`).

## The finding
The coin's famous "no directed triangle until n=4" is a **two-symbol
peculiarity.** With m ≥ 3 symbols nontransitivity *and* the first triangle both
appear at n = 2: on a 3-sided die `01 ▸ 12 ▸ 20 ▸ 01`, each winning exactly 3/5.
The onset gap (triangle − nontransitivity) is 1 for the coin, 0 for every larger
die. Nine new sequences (cyc3 / ties / maxout for m = 3,4,5), all confirmed
absent from OEIS, staged in `/oversight/oeis/penney-mary/`.

## Reproduce
```
node research/penney-mary/verify.mjs        # 18/18 + the tables
node research/penney-mary/explore.mjs       # the concrete triangle
node oversight/oeis/penney-mary/derive.mjs  # rewrite the b-files
```
